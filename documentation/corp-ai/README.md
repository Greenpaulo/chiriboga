# Corp AI documentation

Documentation for the Corp AI (`ai_corp.js`). How the files, statuses, IDs,
template and commands work is shared with the Runner AI and described in
[../ai-planning.md](../ai-planning.md).

| File | Holds |
|---|---|
| [principles.md](principles.md) | Corp-specific rules, on top of [../ai-principles.md](../ai-principles.md) |
| [architecture.md](architecture.md) | How the implemented Corp AI works today |
| [roadmap.md](roadmap.md) | One entry per item (areas L, F, I, R, P) |
| [specs/](specs/) | Specs for `proposed` items, plus the install and reactive design notes |
| [legacy/](legacy/) | The previous Corp AI roadmaps, kept for comparison only |

**Agents:** do not read `legacy/`. For an item, read `../ai-principles.md`,
`principles.md`, the item's ticket or spec, the design note it names, and only
the `architecture.md` sections it links to.
